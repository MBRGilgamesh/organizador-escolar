# organizador-escolar

Aplicativo desenvolvido em Python utilizando Tkinter.

O sistema possui:
* Agenda Escolar
* Checklist de Estudos
* Integração automática entre agenda e checklist
* Salvamento de dados em JSON

## Tecnologias utilizadas
* Python
* Tkinter
* JSON
* VS Code

## Funcionalidades
* Criar eventos escolares
* Excluir eventos
* Criar tarefas de estudo
* Marcar tarefas concluídas
* Persistência de dados

## Objetivo
O projeto foi desenvolvido com o objetivo de auxiliar estudantes na organização acadêmica, integrando agenda escolar e checklist de estudos em um único ambiente.

## Como executar
1. Instale Python
2. Abra o projeto no VS Code
3. Execute:

```bash
python main.py
```
